# SEABIM Editor

User documentation for the **SEABIM Editor** plugin for CloudCompare 2.13.

SEABIM Editor is a plugin that adds breakwater-engineering tools to
CloudCompare for preparing, validating and exporting breakwater structures
from point clouds: automatic block detection, registration, quality
control, metadata management and export to delivery formats.

## Module reference

The interface is organised in tabs. Each tab corresponds to a module; each
module groups several actions accessible from the launcher.

| Module                                 | Purpose                                                       |
| -------------------------------------- | ------------------------------------------------------------- |
| [Header](modules/header.md)            | Cross-cutting actions (undo, color scale, settings)           |
| [Import](modules/input.md)             | Import from clouds, JSON, CSV, block detection                |
| [Edit](modules/edit.md)                | Block editing: registration, deletion, grouping               |
| [Quality control](modules/quality.md)  | Accuracy, duplicates, overlap                                 |
| [Filters](modules/filters.md)          | Quality filters (profile, contacts, voids…)                   |
| [Metadata](modules/metadata.md)        | Per-block and batch metadata editing                          |
| [Export](modules/output.md)            | Export JSON, CSV, final render                                |
